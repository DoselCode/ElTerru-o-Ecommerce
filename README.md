# El Terruño - E-Commerce

Bienvenido al repositorio oficial del e-commerce de **El Terruño** (Almacén Gourmet & Vinos Boutique).

## Estructura del Proyecto
Este proyecto utiliza HTML, CSS (Vanilla) y JavaScript para ofrecer una experiencia web rápida y dinámica. 

- `src/main.js` - Lógica del carrito de compras y notificaciones (toasts).
- `src/style.css` - Sistema de estilos responsivo y variables CSS de la marca.
- `index.html` - Estructura semántica del catálogo y presentación del local.

## Flujo de Trabajo (Git Flow)
Se utiliza un flujo de trabajo basado en la rama `develop` para la integración de nuevas features o fixes, los cuales luego se unen a `main` a través de Pull Requests.

> **Nota:** La rama `main` está conectada al entorno de producción para despliegues automatizados (Vercel/Netlify).

## Scripts Disponibles
Para iniciar el entorno de desarrollo local, instalá las dependencias y ejecutá el servidor:

```bash
npm install
npm run dev
```
